Strategy Briefing

Making Vulcan data products AI-ready with the Open Knowledge Format

For CEO / CPO · Recommendation · July 2026

AI agents are only as good as the context they can reach — and today that context is trapped in incompatible systems. The Open Knowledge Format (OKF), a new vendor-neutral standard from Google Cloud, packages a data product's meaning as portable files any human or agent can read. It already runs in production inside Google Cloud. Because Vulcan already holds the governed metadata OKF needs, emitting it is a low-cost generation step — not a new system — and doing it now puts us early on the standard the ecosystem is converging toward.

01 — The problem

Agents are blocked by missing context, not missing data

The hard part of pointing AI at enterprise data isn't running queries — it's understanding: what a metric means, how it's computed, who owns it, and whether it's still trustworthy. In announcing OKF, Google Cloud puts it plainly: every agent builder re-solves the same context-assembly problem from scratch, every catalog vendor reinvents the same models, and the knowledge stays locked behind whichever surface created it.

This is why the industry is standardizing the connective tissue for AI. Anthropic's Model Context Protocol standardized how agents connect to data and tools; OKF is the complement — a standard for the knowledge itself, the durable meaning around the data.

02 — The standard

What OKF actually is

OKF is an open specification from Google Cloud's Data Cloud team, deliberately vendor-neutral — "format, not platform." A data product becomes a directory of plain Markdown files with a small structured header: no proprietary API, no SDK, readable in any editor and by any agent. It is minimal and versioned, with a public specification on GitHub. And it doesn't invent a new habit — it formalizes one teams already practice, wiring agents to AGENTS.md / CLAUDE.md files and metadata-as-code repositories.

In production

03 — The proof

It already runs in production — at the source

This isn't a paper standard. Google Cloud has built OKF into its Knowledge Catalog, which ingests OKF and serves it to Google's own data agents — and its reference tooling generates OKF automatically by walking a BigQuery dataset and drafting a concept document for every table and view. The format is already the working interface between Google's flagship warehouse and its agents.

OKF is early — released mid-2026, now at v0.2 (adding trust and verification signals) — with Google as its first major adopter. That is exactly the window in which adopting a standard is cheapest and most differentiating, rather than retrofitting after it consolidates.

04 — The value

Why it matters

  • Trust, not just answers. OKF carries provenance, verification, and freshness as first-class signals — an AI answer can be traced and defended, not merely believed.
  • Write once, consumed everywhere. One product becomes usable by internal assistants, data catalogs, search, and partner systems — with no bespoke integration per tool, because they all speak the one open format.
  • A broader standards wave. Open contract and product standards — ODCS under the Linux Foundation's Bitol project and ODPS — already govern how data is described. OKF extends that logic to the AI-context layer, and value accrues to the format the most parties can speak.

05 — The fit

Vulcan makes this effortless

The decisive point: we already have everything OKF needs. Vulcan holds models, metrics, ownership, data quality, and freshness as governed metadata — and already emits two established open standards from it today, ODCS contracts and ODPS product documents. OKF is an incremental generation step on that same foundation:

  • On demand. A complete, standards-compliant bundle for any product, through the same API as our existing contract exports.
  • Always in sync. Regenerated from live metadata as products evolve, with ownership and freshness derived from what Vulcan already tracks.
  • Nothing extra. No new content for teams to author, and no new tool to operate.

Recommendation

Emitting OKF turns data products we already govern into AI-ready assets at near-zero marginal cost — a small, low-risk, reversible step that compounds. Every product becomes discoverable, trustworthy, and reusable by the next generation of AI tools, matching the interface Google already runs between BigQuery and its agents. Ship OKF export as a first-class Vulcan capability.
