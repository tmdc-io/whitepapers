Data Modeling Patterns

A field guide to the patterns for modeling analytical data: normalized, star, snowflake, one big table, Data Vault, anchor, activity schema, and unified star schema. Each pattern has its own chapter, taught from the beginning, on one shared case study. The same twelve stress tests then show where each pattern is strong and where it struggles.

How this field guide works

Every pattern chapter has the same shape. It opens with what the chapter covers, explains the idea in plain words, and builds the pattern step by step for Lantern Pet Supply, a made-up US pet retailer. Numbered figures, tables, and annotated SQL listings carry the details. "Try it" exercises let you run the key ideas in the page. Each chapter ends with its strengths and limits on the twelve stress tests, and a summary.

The SQL is plain ANSI SQL. The guide names no products or platforms. It is about the patterns, which work on any analytical database.
